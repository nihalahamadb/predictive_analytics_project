# Predictive Analytics Using Historical Data

## Project Overview
This project builds a time-series regression model to clean historical sales data, evaluate forecast accuracy, and predict future trends over a 180-day horizon.

## Folder Contents
- `predictive_analytics.py`: Complete, runnable Python script.
- `historical_sales_data.csv`: Raw historical dataset (includes missing values and duplicates to demonstrate cleaning).
- `cleaned_sales_data.csv`: Preprocessed dataset after removing duplicates and interpolating missing values.
- `future_sales_forecast.csv`: 180-day predicted sales output generated by the model.
- `forecast_visualization.png`: High-resolution plot showing historical data, test validation, and future forecast.
- `requirements.txt`: Required Python dependencies.

## Model Performance (Test Set)
- **MAE (Mean Absolute Error):** 15.11
- **RMSE (Root Mean Squared Error):** 19.06
- **R² Score:** 0.7934
- **MAPE (Mean Absolute Percentage Error):** 3.12%

## How to Run Locally
1. Extract this ZIP archive and open a terminal inside the `predictive_analytics_project` folder.
2. Create and activate a virtual environment:
   - Windows: `python -m venv venv && venv\Scripts\activate`
   - Mac/Linux: `python3 -m venv venv && source venv/bin/activate`
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the project:
   ```bash
   python predictive_analytics.py
   ```
